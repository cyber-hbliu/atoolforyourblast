hi this is an unofficial planning tool for Sustain-Release year twelve.

The explore view plots all 57 artists on one coordinate map. The horizontal axis runs from DJ set to live performance and the vertical axis runs from dancefloor to experimental. Squares are colored by group and hovering a name draws dotted trails to related artists through shared genres and labels. Every name links to the artist's own page on Bandcamp, SoundCloud or Instagram.

The timetable view is one continuous grid from Thursday evening to Sunday afternoon. Tap a set to dim what you will skip, and you are able to save your schedule to your phone.

Lineup and set times come from the official Sustain-Release announcements at sustain-release.com.
